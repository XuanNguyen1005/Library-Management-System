# 📚 Hệ Thống Quản Lý Thư Viện (Java Swing & JSON)

Đồ án môn học Lập trình Hướng đối tượng - Xây dựng ứng dụng quản lý thư viện bằng Java Swing.

## ✨ Tính năng chính
* Quản lý danh mục sách, tài liệu, tạp chí và luận văn.
* Quản lý người đọc (Sinh viên, Giảng viên).
* Theo dõi mượn/trả sách và lịch sử giao dịch.
* Lưu trữ dữ liệu cục bộ an toàn qua định dạng JSON (`thư viện.json`).

## 🛠️ Công nghệ sử dụng
* **Ngôn ngữ:** Java (JDK 8+)
* **Giao diện:** Java Swing
* **Lưu trữ dữ liệu:** JSON
* **Công cụ phát triển:** VS Code, Git/GitHub
